# SQL QA Portfolio: Тестирование данных и валидация бизнес-логики

Репозиторий содержит примеры SQL-запросов, разработанных для решения QA-задач: верификации данных, поиска аномалий, проверки валидации на бэкенде и сверки аналитических отчетов.

## 🛠 Стек технологий и инструменты
* **СУБД:** MySQL
* **Платформы тестирования:** Публичные интерактивные песочницы и тренажеры (SQL Academy и др.)

## 📂 Структура репозитория
* `/queries/01_smoke_checks.sql` — Базовые проверки на целостность данных и наличие `NULL` значений.
* `/queries/02_data_filtering.sql` — Проверка граничных значений, диапазонов и валидация форматов (Email/Телефоны) с помощью операторов `LIKE` и `REGEXP`.
* `/queries/03_analytical_qa.sql` — Сложные проверки бизнес-логики со связыванием таблиц (`JOIN`), агрегацией (`SUM`, `AVG`, `COUNT`) и фильтрацией сгруппированных данных (`HAVING`).

## 📈 Примеры QA-сценариев, покрытых запросами:
1. **Проверка валидации полей:** Выявление записей с нарушенной логикой обязательности полей (поиск критических `NULL` значений в личных данных).
2. **Тестирование масок и регулярных выражений:** Проверка корректности записи телефонных номеров (формат `+7...`) и доменных имен почтовых ящиков на бэкенде.
3. **Сверка данных бэкенда с UI:** Запросы с использованием `JOIN` и агрегатных функций для перепроверки правильности построения графиков и таблиц в административной панели приложения.
